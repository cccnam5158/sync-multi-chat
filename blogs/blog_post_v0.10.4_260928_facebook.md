Sync Multi Chat v0.10.4 업데이트 안내

macOS에서 업데이트를 받을 때 "Downloading update..." 진행 창이 다운로드가 끝난 뒤에도 사라지지 않던 문제를 고쳤습니다. Intel Mac 테스트 빌드로 다운로드 → 검증 → DMG 열기 → 진행 창 닫힘까지 끝까지 확인했습니다.

v0.10.2 이하 Mac 사용자는 앱의 업데이트 버튼에서 "Could not get code signature for running application" 오류가 계속 보일 수 있습니다. 이번 한 번만 아래 릴리스 페이지에서 칩(Apple Silicon/Intel)에 맞는 DMG를 받아 설치해 주세요. 그 다음부터는 앱 안에서 바로 업데이트됩니다.

Windows 설치 파일은 GitHub Actions에서 빌드하고, macOS는 Apple Silicon·Intel 각각의 DMG를 같은 Release에 올립니다.

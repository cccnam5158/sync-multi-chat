Sync Multi Chat v0.10.2 업데이트 안내

ChatGPT의 새 입력창(ProseMirror composer)과 전송 버튼에 맞춰 프롬프트 전송 로직을 개선했습니다. ChatGPT 패널에만 프롬프트가 입력되지 않거나 전송이 멈추던 현상이 해결되었고, 로그인 상태 탐지·Copy Chat Thread·Copy Last Response·Cross Check도 최신 ChatGPT 화면에서 동작합니다.

Windows 설치 파일은 GitHub Actions에서 빌드하고, macOS는 Apple Silicon·Intel 각각의 DMG를 같은 Release에 올립니다.

Sync Multi Chat v0.10.3 업데이트 안내

Gemini의 새 입력창에서 Cross Check를 하면 첫 줄(기본 프롬프트)만 전달되고 ChatGPT·Claude의 답변이 빠지던 문제를 고쳤습니다. 이제 Gemini에도 다른 AI의 답변이 모두 담긴 프롬프트가 전송됩니다.

Intel Mac에서 자동 업데이트가 "Could not get code signature for running application" 오류로 끝나지 않던 문제도 해결했습니다. Update Now를 누르면 내 Mac 칩에 맞는 DMG를 받아 검증한 뒤 열어 주고, 응용 프로그램 폴더로 드래그하면 업데이트가 끝납니다. v0.10.2 이하 Mac 사용자는 v0.10.3을 한 번만 직접 받아 설치해 주세요.

Windows 설치 파일은 GitHub Actions에서 빌드하고, macOS는 Apple Silicon·Intel 각각의 DMG를 같은 Release에 올립니다.
